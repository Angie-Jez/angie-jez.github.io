AML Entity Resolution & Transaction Monitoring Pipeline

An end-to-end financial-crime detection pipeline combining vector-search entity resolution against a watchlist with ML-based transaction anomaly scoring. Built from scratch to work through a real problem I'd encountered before: common names causing false-positive matches in sensitive identity checks.

Adding date of birth as a secondary identity signal eliminated every false escalation on common-name collisions, while still correctly catching 14 of 15 disguised watchlist aliases.
